## English

This repository contains exclusively **Community Applications Templates** for the **HEL\*Apps** — a collection of self-developed homelab applications optimized for use on [Unraid](https://unraid.net/).

### 🗂️ What is this?

The `.xml` files in this repository are **Unraid CA templates**. They allow easy installation of the HEL\*Apps directly via the **Community Applications plugin** in Unraid — no manual configuration required.

Each template includes:
- pre-configured container settings
- recommended `appdata` paths
- relevant environment variables with descriptions
- optional mounts and ports

### 🔗 Related Repositories

The source code repositories for each app are hosted separately. This repo serves **exclusively** as a template source for Unraid.

### ⚠️ Notice

All HEL\*Apps were developed with the assistance of AI and are provided without warranty. No professional code review or security audit has been performed. The apps are intended exclusively for **private homelab use within a local network** and must **never be exposed to the public internet**. Use entirely at your own risk.
